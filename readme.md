# Portafolio Web - Erick Calderón

## Descripción del Proyecto

Portafolio web personal responsive desarrollado para mostrar habilidades, tecnologías dominadas y proyectos destacados de desarrollo web full-stack junior. El proyecto se adapta a diferentes tamaños de pantalla (1440px, 768px y 320px) manteniendo una maquetación limpia y accesible.

## Tecnologías y Técnicas Utilizadas

- **HTML5**: Estructura semántica del contenido (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Estilos, metodología BEM, Flexbox, fuentes personalizadas con `@font-face` y degradados.
- **Diseño Responsivo**: Consultas de medios (`@media`) ajustadas para escritorio, tableta y dispositivos móviles.
- **Git y GitHub Pages**: Control de versiones y despliegue continuo.
